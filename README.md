# Seesvee

A minimalist, fast CSV viewer and editor for macOS, written in Rust with
[gpui](https://github.com/zed-industries/zed/tree/main/crates/gpui).

## Download

**[Download Seesvee for macOS (Apple Silicon)](https://github.com/dctanner/seesvee/releases/latest/download/Seesvee-macos-arm64.zip)**

1. Unzip it and drag **Seesvee.app** into **Applications**.
2. The app is ad-hoc signed but not notarized, so macOS blocks it the first time.
   Open it once, then go to **System Settings → Privacy & Security** and click
   **Open Anyway**. Or clear the download flag from Terminal:

   ```sh
   xattr -dr com.apple.quarantine /Applications/Seesvee.app
   ```

On its first launch Seesvee makes itself the default app for `.csv` files, so
double-clicking a CSV in Finder opens it here. It only does this once; if you
pick another default later, that choice sticks. You can claim CSV files again with
**Seesvee → Make Default App for CSV Files**. TSV files can be opened too.

## Build from source

```sh
cargo run --release -- path/to/file.csv
```

To build the app bundle and zip (`target/release/Seesvee.app`,
`target/release/Seesvee-macos-arm64.zip`), and optionally install it:

```sh
./scripts/bundle-macos.sh             # build only
./scripts/bundle-macos.sh --install   # also copy to /Applications and launch
```

gpui is pinned to the last Zed commit that builds on Rust 1.93 (Zed `main`
currently needs 1.98). Metal shaders are compiled at runtime by default so the
build doesn't need Xcode's Metal toolchain; after
`xcodebuild -downloadComponent MetalToolchain` you can build with
`--no-default-features` to precompile them. The icon is generated by
`swift scripts/make-icon.swift`.

## Using it

| Action | How |
| --- | --- |
| Sort | Click a column header: ascending → descending → file order |
| Resize a column | Drag its right edge; double-click the edge to autofit |
| Move a column / row | Drag its header |
| Filter | Click the ⌄ button on a header, or right-click → Filter… |
| Column / row / cell menus | Right-click a header, row number or cell |
| Edit a cell | Double-click, press Enter or F2, or just start typing |
| Commit an edit | Enter (down), Tab (right), Shift-Enter / Shift-Tab, arrow up/down; Esc cancels; ⌥Enter inserts a line break |
| Select | Click, Shift-click, drag; click row numbers for rows; ⌘/Shift-click headers for columns |
| Copy / paste | ⌘C / ⌘V as tab-separated values (works with Numbers, Excel, Sheets) |
| Undo / redo | ⌘Z / ⇧⌘Z |
| Save / Save As | ⌘S / ⇧⌘S |

**Saving writes exactly what you see.** Columns are written in their on-screen
order, rows in their on-screen (sorted) order, and rows hidden by a filter are
left out. The status bar warns when a filter is active.

The delimiter (comma, tab, semicolon, pipe) is detected automatically and can be
overridden with File → Reopen With Delimiter. Line endings, a UTF-8 BOM and
UTF-16 encoding are preserved on save; files that aren't valid UTF-8 are read as
Windows-1252 and saved as UTF-8.

## Problems in a file

Malformed files still open. Every problem is listed with its line number and
column, and the affected rows are marked in red:

- rows with more or fewer fields than the header (often an unquoted delimiter)
- quotes that are never closed (recovered at the end of the line)
- stray quotes inside unquoted fields, or text after a closing quote
- quoted values that span lines, a hint for an unbalanced quote
- invalid UTF-8 and duplicate column names

Click a problem to jump to it. `samples/broken.csv` shows each case.

## Development

```sh
cargo test
SEESVEE_BENCH=big.csv cargo test --release bench -- --ignored --nocapture
```

The tests cover the parser, the document model (sorting, filters, row and
column operations, undo, saving) and the UI itself, driving the real editor with
simulated clicks, drags and keystrokes through gpui's headless test platform.

| Module | Purpose |
| --- | --- |
| `parse.rs` | Delimiter sniffing, decoding, and the diagnosing parser |
| `store.rs` | Compact cell storage: one string arena plus an edit overlay |
| `document.rs` | Columns, row order, sort, filters, undo and serialization |
| `grid.rs` | The custom-painted, row- and column-virtualized grid |
| `editor.rs` | The window view: selection, editing, menus, clipboard, files |
| `filter_panel.rs` | The column filter popover |
| `text_input.rs` | Single-line text field (adapted from gpui's input example) |
| `default_app.rs` | Registering as the default CSV app with LaunchServices |
